# Revisão por lentes

Revise diff e fluxo de execução usando lentes de correção, autorização, dados, testes e operação. Cada achado precisa de arquivo/linha, cenário concreto de falha, impacto e correção sugerida. Deduplicate e ordene por impacto. Revisores independentes somente se houver autorização e suporte; não delegue só por ler este documento. Sem isso, declare autorrevisão sequencial. Não invente achados para preencher relatório.

## Evidência de conclusão

Registre o que foi feito, os comandos realmente executados e seus resultados, pendências e justificativas. Uma instrução escrita não comprova execução.
