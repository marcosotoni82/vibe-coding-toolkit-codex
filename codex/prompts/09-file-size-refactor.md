# Refatoração por responsabilidade

Meça arquivos acima do teto, inspecione dependentes e escolha uma unidade de responsabilidade. Extraia preservando API pública e comportamento. Não divida por contagem de linhas nem esconda código em módulos genéricos. Rode testes relevantes, lint e typecheck entre mudanças. Sem fronteira natural, documente exceção com motivo. Faça commits somente dentro da autorização da tarefa; nunca inclua trabalho de terceiros.

## Evidência de conclusão

Registre o que foi feito, os comandos realmente executados e seus resultados, pendências e justificativas. Uma instrução escrita não comprova execução.
